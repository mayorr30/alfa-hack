# Умный кредитный кабинет предпринимателя — MVP Прототип

Цифровой кредитный конвейер для малого и микробизнеса, объединяющий клиентский путь и внутреннюю автоматизированную обработку кредитных заявок в единый сквозной процесс на базе ML-модели.

## 🏗️ Архитектура и Стек технологий
* **Backend:** Python 3.13 + FastAPI (асинхронная обработка запросов)
* **Database:** PostgreSQL 15 + SQLAlchemy (AsyncPG драйвер)
* **Migrations:** Alembic (автоматическое управление схемами данных)
* **Package Manager:** uv (Astral) — современный скоростной менеджер зависимостей
* **ML-Engine:** Scikit-Learn + Joblib (интеграция готовой скоринговой модели `credit_ml`)
* **Infrastructure:** Docker + Docker Compose (контейнеризация сервисов)
* **Frontend:** Встроенный UI-интерфейс на Jinja2-шаблонах с интеграцией Bootstrap 5

## 🛠️ Требования к окружению
* Установленный и запущенный **Docker Desktop** (с поддержкой Docker Compose)
* Локально установленный **Python 3.13** и пакетный менеджер **uv** (для разработки и тестов)

## 🚀 Пошаговый запуск проекта

### 1. Локальный запуск через Docker Compose (Рекомендуется для жюри)
Для развертывания всего конвейера и базы данных одной командой, выполните в корне проекта:
```bash
docker compose up --build
```
После успешного запуска веб-интерфейс будет доступен по адресу: `http://localhost:8000/`  
Интерактивная документация API (Swagger/OpenAPI): `http://localhost:8000/docs`

### 2. Локальный запуск для разработки (внутри venv)
Если необходимо запустить компоненты вручную:
```bash
# Установка зависимостей
uv sync

# Запуск СУБД в Docker
docker compose up -d db

# Накатывание миграций таблиц БД
uv run alembic upgrade head

# Запуск сервера разработки FastAPI
uv run uvicorn src.main:app --reload --port 8000
```

## 🧪 Сценарий технической проверки и демонстрации

В системе реализовано автономное тестирование и эмуляция (мокирование) закрытых государственных сервисов (ФНС «Прозрачный бизнес», БКИ):

1. **Кейс одобрения:** Перейдите в веб-интерфейс (`http://localhost:8000/`), введите любой валидный 12-значный ИНН (например, `773544899576`), укажите желаемую сумму и срок. Нажмите «Отправить на скоринг». Сервис сымитирует идеальные финансовые показатели и модель выдаст статус **ОДОБРЕНО**.
2. **Кейс отказа с расшифровкой причин:** Введите ИНН, начинающийся с трех нулей (например, `000123456789`). Система через моки вернет плохие стоп-факторы (наличие просрочек, нулевая выручка). Модель выдаст **ОТКАЗ** и автоматически выведет на экран структурированные причины принятия решения на основе модуля `reasons.py`.

### Запуск автоматических тестов:
```bash
uv run pytest
```
